# آشنایی با ویراست‌های مختلف جاوا

در دنیای جاوا، پلتفرم جاوا به چند Edition (ویراست) تقسیم شده که هر کدام
برای نوع خاصی از توسعه نرم‌افزار طراحی شده‌اند.

## معماری کلی جاوا

``` text
Java Platform
│
├── Java SE
├── Java EE (Jakarta EE)
├── Java ME
├── Java Card
├── JavaFX
└── Embedded Java
```

------------------------------------------------------------------------

# 1. Java SE (Standard Edition)

مادر همه نسخه‌های جاوا و پایه اصلی توسعه نرم‌افزارهای جاوایی.

شامل:

-   JVM
-   JDK
-   Collections
-   Streams
-   JDBC
-   Multithreading
-   File I/O
-   Networking
-   Reflection

کاربردها:

-   برنامه‌های کنسولی
-   نرم‌افزارهای دسکتاپ
-   کتابخانه‌ها
-   ابزارهای سیستمی

------------------------------------------------------------------------

# 2. Java EE / Jakarta EE

نسخه سازمانی جاوا برای توسعه سیستم‌های بزرگ.

کاربردها:

-   بانکداری
-   بیمه
-   ERP
-   CRM
-   سامانه‌های بیمارستانی
-   سرویس‌های تحت وب

امکانات:

-   REST API
-   Dependency Injection
-   Security
-   Transactions
-   Messaging

فریم‌ورک‌های مشهور:

-   Spring Framework
-   Hibernate

------------------------------------------------------------------------

# 3. Java ME (Micro Edition)

برای دستگاه‌های کم‌قدرت طراحی شده است.

نمونه دستگاه‌ها:

-   گوشی‌های قدیمی نوکیا
-   PDA
-   ترمینال‌های پرداخت
-   دستگاه‌های صنعتی

فایل‌های مشهور:

``` text
.jar
.jad
```

------------------------------------------------------------------------

# 4. Java Card

نسخه بسیار کوچک جاوا برای کارت‌های هوشمند.

کاربردها:

-   کارت بانکی
-   سیم‌کارت
-   کارت ملی هوشمند
-   کارت‌های امنیتی

حافظه معمول:

``` text
8KB
16KB
64KB
```

------------------------------------------------------------------------

# 5. JavaFX

کتابخانه رابط کاربری مدرن جاوا.

قابلیت‌ها:

-   Animation
-   CSS Styling
-   Media Player
-   2D/3D Graphics

کاربردها:

-   نرم‌افزارهای دسکتاپ
-   داشبوردها
-   مدیا پلیرها

------------------------------------------------------------------------

# 6. Swing

کتابخانه کلاسیک رابط کاربری جاوا.

ویژگی‌ها:

-   پایدار
-   سبک
-   قدیمی اما پرکاربرد

بسیاری از نرم‌افزارهای سازمانی قدیمی هنوز با Swing توسعه یافته‌اند.

------------------------------------------------------------------------

# 7. Embedded Java

برای سیستم‌های نهفته.

کاربردها:

-   ATM
-   دستگاه پزشکی
-   روتر
-   کنترل صنعتی

------------------------------------------------------------------------

# 8. Android Java

اندروید مستقیماً Java SE نیست.

در ابتدا:

-   زبان Java
-   ماشین مجازی Dalvik

استفاده می‌شد.

امروزه:

-   Java
-   Kotlin

روی Android Runtime (ART) اجرا می‌شوند.

------------------------------------------------------------------------

# 9. GraalVM

نسخه مدرن و پیشرفته JVM.

مزایا:

-   تبدیل Java به فایل اجرایی Native
-   سرعت اجرای بالا
-   مصرف حافظه کمتر
-   عدم نیاز به JVM روی سیستم مقصد

نمونه:

``` text
Java → Native EXE
```

------------------------------------------------------------------------

# جدول خلاصه

  نسخه            کاربرد
  --------------- -------------------------
  Java SE         توسعه استاندارد جاوا
  Jakarta EE      سامانه‌های سازمانی و وب
  Java ME         دستگاه‌های کم‌قدرت
  Java Card       کارت‌های هوشمند
  JavaFX          رابط کاربری مدرن
  Swing           رابط کاربری کلاسیک
  Embedded Java   سیستم‌های نهفته
  Android Java    توسعه اندروید
  GraalVM         ساخت فایل اجرایی Native

------------------------------------------------------------------------
