# JDK، JRE، JVM و اجزای مرتبط در جاوا

این سند به معرفی مهم‌ترین اجزای معماری جاوا می‌پردازد: JDK، JRE، JVM و
مفاهیم مرتبط مانند JIT، Garbage Collector، Bytecode و غیره.

------------------------------------------------------------------------

# معماری اجرای جاوا

``` text
Source Code (.java)
        │
        ▼
      JDK
   (Compiler)
        │
        ▼
 Bytecode (.class)
        │
        ▼
      JVM
        │
        ▼
 Operating System
```

------------------------------------------------------------------------

# 1. JVM چیست؟

JVM مخفف Java Virtual Machine است.

وظایف اصلی:

-   اجرای Bytecode جاوا
-   مدیریت حافظه
-   Garbage Collection
-   مدیریت Threadها
-   ارتباط با سیستم‌عامل

مزیت اصلی:

``` text
Write Once, Run Anywhere
```

یک برنامه جاوا می‌تواند روی ویندوز، لینوکس و macOS بدون تغییر اجرا شود.

------------------------------------------------------------------------

# 2. JRE چیست؟

JRE مخفف Java Runtime Environment است.

ساختار:

``` text
JRE
│
├── JVM
└── Java Libraries
```

وظیفه:

-   اجرای برنامه‌های جاوا
-   فراهم کردن کتابخانه‌های استاندارد جاوا

اگر فقط بخواهید برنامه جاوا را اجرا کنید، JRE کافی است.

------------------------------------------------------------------------

# 3. JDK چیست؟

JDK مخفف Java Development Kit است.

ساختار:

``` text
JDK
│
├── JRE
│   └── JVM
│
├── javac
├── jar
├── javadoc
├── jdb
└── سایر ابزارها
```

JDK برای توسعه‌دهندگان استفاده می‌شود.

------------------------------------------------------------------------

## ابزارهای مهم JDK

### javac

کامپایلر جاوا

``` bash
javac Main.java
```

تبدیل:

``` text
Main.java
↓
Main.class
```

------------------------------------------------------------------------

### java

اجرای برنامه

``` bash
java Main
```

------------------------------------------------------------------------

### jar

ساخت فایل JAR

``` bash
jar cf app.jar
```

------------------------------------------------------------------------

### javadoc

تولید مستندات خودکار

------------------------------------------------------------------------

### jdb

دیباگر جاوا

# 4. JIT چیست؟

JIT مخفف Just In Time Compiler است.

بخشی از JVM بوده و وظیفه آن تبدیل Bytecode به Machine Code در زمان اجرا
است.

مزایا:

-   افزایش سرعت اجرا
-   بهینه‌سازی کدهای پرتکرار

------------------------------------------------------------------------

# 5. Garbage Collector (GC)

سیستم مدیریت حافظه جاوا.

وظایف:

-   شناسایی اشیای بلااستفاده
-   آزادسازی حافظه

مزیت:

نیازی به آزادسازی دستی حافظه مانند C و C++ نیست.

------------------------------------------------------------------------

# 6. Bytecode چیست؟

خروجی کامپایلر جاوا:

``` text
.class
```

ویژگی‌ها:

-   مستقل از سیستم‌عامل
-   قابل اجرا توسط JVM

------------------------------------------------------------------------

# 7. ClassLoader

بخشی از JVM.

وظیفه:

-   بارگذاری کلاس‌ها هنگام اجرا

نمونه کلاس‌ها:

``` java
ArrayList
HashMap
Scanner
```

------------------------------------------------------------------------

# 8. Java Compiler

ابزار:

``` text
javac
```

وظیفه:

``` text
.java
↓
.class
```

------------------------------------------------------------------------

# 9. JAR چیست؟

JAR مخفف Java Archive است.

نمونه:

``` text
myapp.jar
```

ویژگی‌ها:

-   بسته‌بندی برنامه‌های جاوا
-   مشابه فایل ZIP
-   قابل اجرا توسط JVM

اجرا:

``` bash
java -jar myapp.jar
```

------------------------------------------------------------------------

# 10. JNI چیست؟

JNI مخفف Java Native Interface است.

کاربرد:

-   ارتباط جاوا با C
-   ارتباط جاوا با C++
-   استفاده از کتابخانه‌های Native

نمونه:

``` java
native void myFunction();
```

------------------------------------------------------------------------

# 11. Java Modules

از Java 9 معرفی شد.

فایل اصلی:

``` text
module-info.java
```

مزایا:

-   مدیریت وابستگی‌ها
-   امنیت بیشتر
-   ساختاردهی بهتر پروژه

------------------------------------------------------------------------

# 12. GraalVM

نسل جدید JVM.

قابلیت مهم:

``` text
Java
↓
Native EXE
```

مزایا:

-   سرعت اجرای بالاتر
-   مصرف حافظه کمتر
-   امکان ساخت فایل اجرایی مستقل بدون JVM
